# Shizuku 免电脑常驻与系统级 API 桥接实战指南

## 1. 什么是 Shizuku？

Shizuku 是一款由 Rikka 开发的划时代 Android 系统工具。
它的核心设计理念是：**将 ADB Shell (UID 2000) 权限通过标准 Android Binder 接口暴露给普通应用**。

- 传统场景：第三方应用想要修改应用权限、静默安装、冻结后台，必须获取手机 Root 权限。
- Shizuku 场景：第三方应用只需申请 Shizuku 权限，即可间接以 ADB Shell 的身份执行系统特权 API，无需修改任何系统分区，亦无需解锁 Bootloader。

## 2. 荣耀 MagicOS 本地配对与无线启动流程

现代荣耀手机（MagicOS 7.0 / 8.0 / 9.0，基于 Android 13/14/15）原生支持「无线调试」功能，这意味着你可以直接在手机上完成 Shizuku 的启动，不再依赖电脑 USB 数据线！

### 步骤 1：准备软件
1. 从官方渠道或应用市场下载并安装 **Shizuku**。
2. 确保手机已连接至 Wi-Fi 网络（手机端无线调试要求当前网络接口处于活动状态）。

### 步骤 2：开启手机无线调试
1. 进入「设置」->「系统和更新」->「开发人员选项」。
2. 找到并打开「无线调试」开关。
3. 勾选「始终允许在此网络上进行调试」。

### 步骤 3：本地配对
1. 在「开发人员选项」中点击「使用配对码配对设备」。
2. 屏幕上将弹出 6 位数字的 Wi-Fi 配对码以及 IP 地址和端口号。
3. 下拉通知栏，在 Shizuku 的配对通知中输入这 6 位配对码并点击发送。
4. 看到「配对成功」提示后，返回 Shizuku 主界面。

### 步骤 4：启动 Shizuku 服务
1. 在 Shizuku 主界面，点击「启动」按钮。
2. Shizuku 会自动通过本地回环地址 (`127.0.0.1`) 建立 ADB 会话并启动服务。
3. 界面显示「Shizuku 正在运行 (版本 XXX, adb 模式)」即宣告成功！

## 3. Shizuku 生态下强大的免 Root 神器推荐

Shizuku 启动后，你可以在荣耀手机上无缝使用以下高阶工具：

1. **小黑屋 / 冰箱 (IceBox) - Shizuku 模式**：
   - 一键冻结不常用的流氓软件，彻底斩断链式唤醒与后台耗电。
2. **App Ops (权限管理专家)**：
   - 彻底关闭系统应用的剪贴板读取、通知栏推送、唤醒锁等深层权限。
3. **Hail (开源冻结与应用管理)**：
   - 极简、开源、轻量级的应用冻结与隐藏工具。
4. **Scene (性能监控与高刷调节)**：
   - 在免 Root 模式下监控实时帧率、CPU/GPU 占用与调度状态。
5. **Install With Options / SAI**：
   - 免确认静默安装、降级安装、APKs 多分卷安装包快速解析。
